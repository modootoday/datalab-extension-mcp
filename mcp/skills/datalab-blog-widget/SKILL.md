# 네이버 블로그 위젯 HTML

사용자가 자기 네이버 블로그 사이드바나 본문에 붙여넣는 HTML 조각을 만든다. 이 확장의
편집기 컴포넌트와는 무관한 이름이다 — 헷갈리지 않는다.

## 이 스킬이 만들지 않는 것

- **동작하는 위젯.** 계산기·타이머·날씨·투표 — 네이버 블로그는 스크립트와 모든 이벤트
  핸들러를 막는다. 숫자 버튼만 있고 계산은 안 되는 가짜 계산기를 만들지 않는다.
- **발행이나 설치.** 이 확장은 사용자의 블로그 스킨에 아무것도 쓰지 않는다. 산출물은
  사용자가 네이버 블로그 "위젯 만들기" 또는 글쓰기 HTML 모드에 직접 붙여넣는 텍스트다.
- **점수 매긴 검증 리포트.** 통과·실패 체크리스트만 준다.
- **hover 효과.** 네이버는 `<style>` 태그도 `onmouseover` 도 막아서 구현할 방법이 없다.
  링크는 정적 스타일로만 표현한다.

## 무엇을 만드나

1. **위젯** — 170px 고정폭 사이드바용: 프로필 카드, 최근 게시물, 방문자 카운터, 카테고리
   메뉴, 소셜 링크
2. **프로필·소개 섹션** — 본문에 넣는 섹션
3. **게시물 목록** — 본문·사이드바 겸용
4. **카테고리 메뉴** — 링크 목록 패턴

넷 다 같은 제약을 따른다 — `references/naver-constraints.md`.

## 절차

1. 유형(위젯·프로필·목록·카테고리)과 들어갈 내용을 확인한다. 모호하면 먼저 묻는다.
2. `references/naver-constraints.md` 의 태그·바이트 규칙을 따른다.
3. `references/templates.md` 에서 가장 가까운 템플릿을 골라 변형한다. 새 유형이면 `span`
   전용 구조로 새로 짠다.
4. **숫자가 들어갈 자리**(방문자 수, 조회수, 게시물 수):
   - 사용자가 실제 값을 요청했으면 `my_daily_brief` · `my_realtime` · `my_top_content` 로
     값을 가져와 채운다. 채운 숫자 옆에는 **반드시 기준 날짜를 작게 붙인다** — 이 위젯은
     붙여넣는 순간 정지 화면이 되고 자동으로 갱신되지 않는다. 최신 상태를 유지하려면
     다시 생성해서 교체해야 한다고 안내한다.
   - 그 외에는 `0000` 처럼 한눈에 가짜임을 알 수 있는 자리표시자를 쓰고 "실제 숫자로
     바꾸세요"라고 옆에 적는다. `1,234` 처럼 그럴듯한 값은 쓰지 않는다 — 사용자가 그대로
     붙여넣으면 진짜 통계처럼 보인다.
5. 바이트를 센다(위젯 2,000바이트). 초과하면 장식부터 줄인다.
6. HTML 코드 블록으로 낸다 — 이게 유일한 전달 방식이다. 대화 본문에 같은 HTML을 다시
   풀어쓰지 않는다.
7. 마지막에 한 줄: "네이버 블로그 관리 > 꾸미기 설정 > 위젯 만들기(또는 글쓰기 HTML
   모드)에 붙여넣고 미리보기로 확인 후 저장하세요."

## 하드 룰

근거는 `references/naver-constraints.md`.

- 태그는 `span` · `br` · `hr` · `img` · `a` 다섯 개만.
- 모든 링크에 `target="_top"`. 없거나 `_blank` 면 깨진다.
- 인라인 `style` 외 스타일 금지 — `<style>`, `<link>`, class 없음.
- 이벤트 핸들러, `javascript:`, 스크립트 전부 금지. 대체 수단 없음.
- 이모지는 HTML 엔티티로 — 문자 그대로 쓰지 않는다.

2,000바이트 제한은 사용자가 붙여넣기 실패나 잘림을 보고하면 이 문서보다 **실제 네이버
에디터의 반응을 믿는다.**
