# 출력 형식

```
소재 제안

대상: {플랫폼} / {카테고리}{, 타겟 — 있으면}

1. {소재명} — {유형: 트렌드형|에버그린형|니치형|리사이클형}
   앵글: {한 문장}
   근거: {조사에서 확인한 사실 인용 — 검색어, 순위, 상위 글 개수 등}
   비어 있는 부분: {상위 글이 안 다루는 것 — 없으면 생략}

2. ...
(3~7개, 최소 3개, 앵글은 최소 3종 다르게)

확장/시리즈 (해당하면)
{소재} → {시리즈화 방향}
```

## 소재당 반드시 있어야 하는 것

- **근거** — 조사 단계에서 실제로 확인한 것 하나. 확인한 게 없으면(다른 플랫폼 등)
  "일반 패턴 기반, 실측 확인 안 됨" 이라고 적는다.
- **유형** — 트렌드형·에버그린형·니치형·리사이클형 중 하나. 범주일 뿐 점수가 아니다.

## 간단 모드

사용자가 "빠르게" 또는 "간단히" 라고 했을 때만: 소재 3개, 한 줄씩. "1. {소재명} — {앵글}".

## 넣지 않는 것

아래는 결과물에 넣지 않는다. 요청받아도 왜 안 되는지 설명하고 대신 근거를 인용한다.

| 뺀 것                                                          | 왜                                                   |
| -------------------------------------------------------------- | ---------------------------------------------------- |
| 추천도 %, 별점                                                 | 계산한 적 없는 수                                    |
| 검색잠재력·참여유발력·차별화·실현가능성·확장가능성 가중치 점수 | 채점 기준이 없다. 도구가 준 숫자를 인용하는 게 낫다  |
| 난이도 등급(쉬움~어려움)                                       | 실제로 재본 적 없는 주관적 등급                      |
| "심층 검색으로 조사하라"는 안내                                | 이 패널엔 그 도구가 없다 — 실제 도구 호출로 대체했다 |
| "최적 발행 시점 오전 10시" 류 확정 문장                        | 확인 없이 넣은 추정. 근거가 있을 때만 쓴다           |
| 사례의 예시 점수(95%, 92%, 81/100 등)                          | 같은 이유                                            |
