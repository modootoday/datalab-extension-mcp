# 장면 구조

## 역할

- **HOOK** — 첫 장면. 3초 안에 시선을 끄는 한 줄.
- **BODY** — 정보 전달. 한 장면에 한 메시지.
- **CTA** — 마지막 장면. 행동 유도 문구.

장면이 3개뿐이면 HOOK + BODY + CTA로 충분하다. 5~8장이면 HOOK 1 + BODY 3~6 + CTA 1이 흔한
배분이다. 장면 수가 늘어난다고 억지로 세 역할을 다 채우지 않는다.

## 자막 — 넣기 전에 정할 것

검증해 주는 도구는 없으니 상한을 넘겨도 오류는 나지 않는다. 한 장면 안에서 한 호흡에
읽히게 스스로 지키는 기준으로 쓴다.

| 구간 | 용도         | 대략 상한 | 비고                     |
| ---- | ------------ | --------- | ------------------------ |
| HOOK | 첫 문장      | 20자      | 짧고 강하게              |
| BODY | 설명 한 단락 | 40자      | 장면당 메시지 하나       |
| CTA  | 행동 유도    | 20자      | 계정·다음 영상 언급 가능 |

장면 길이는 자막 길이로 자동 추정된다. 문장이 길면 장면을 나눈다.

## 전환과 움직임

- 전환은 영상 전체에서 한두 가지로 통일한다. fade 가 무난한 기본값이다.
- 움직임은 장면마다 달라도 되지만 같은 방향을 연달아 쓰지 않는다 — pan-left 다음 pan-left 는
  지루하고, zoom-in 다음 zoom-out 은 어지럽다.
- HOOK·CTA 에는 강한 움직임이, BODY 에는 없거나 약한 움직임이 흔한 배분이다.

## 화면 비율

| 용도            | 크기(px)    |
| --------------- | ----------- |
| 세로 숏폼(9:16) | 1080 x 1920 |
| 가로(16:9)      | 1920 x 1080 |
| 정사각(1:1)     | 1080 x 1080 |

가로·세로 모두 짝수 픽셀이어야 인코더가 받는다. 모르면 세로 숏폼을 기본값으로 쓰고, 바꿔야
하면 **장면을 만들기 전에** 다시 비율을 맞춘다.
