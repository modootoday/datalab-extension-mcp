# 스타일 어휘

사진 장르, 스타일, 조명 표현을 말로 옮길 때 참고하는 어휘다. 카메라·렌즈 모델명은 다루지
않는다 — 어떤 장비로 찍히는지 알 수 없고, 안다고 말할 수도 없다.

## 사진 장르

- 인물 — 표정과 눈에 초점, 배경이 흐려지는 얕은 심도
- 풍경 — 넓은 시야, 하늘과 지평선의 비중이 큼
- 제품 — 깔끔한 배경, 질감이 잘 보이는 정면·측면 조명
- 음식 — 위에서 내려다보거나 45도, 따뜻한 색감
- 스트리트 — 자연스러운 순간, 인위적이지 않은 구도
- 패션 — 스타일리시한 포즈, 의상 디테일 강조

## 무드

- 밝고 경쾌한 / 차분하고 정적인 / 드라마틱하고 대비가 강한
- 몽환적이고 부드러운 / 빈티지하고 따뜻한 / 미니멀하고 여백이 많은

## 조명 표현 (숫자 없이 말로만)

- 골든아워 — 노을빛, 길게 늘어지는 그림자, 따뜻한 톤
- 창가 자연광 — 방향성 있는 부드러운 빛
- 역광·림라이트 — 피사체 윤곽을 따라 빛나는 테두리
- 흐린 날 확산광 — 그림자가 거의 없는 균일한 빛
- 스튜디오 조명 — 통제된, 균일하고 깨끗한 빛

## 색감 방향

- 따뜻한 톤(주황·노랑 계열) / 차가운 톤(파랑·청록 계열)
- 비비드(채도 높음) / 뮤트(채도 낮음) / 파스텔 / 흑백

## 시대 감성 (선택적으로만)

- 필름 느낌(입자감, 약간 바랜 색) / 메탈릭하고 채도 높은 / 현대적이고 깨끗한
