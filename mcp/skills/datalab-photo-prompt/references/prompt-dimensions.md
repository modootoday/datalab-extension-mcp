# 프롬프트를 채우는 축

새 사진을 만드는 데 실제로 쓰이는 축만 다룬다. 장비 설정 추정·구도 규칙 판정·품질 채점처럼
근거 없이 판단하는 항목은 없다.

## 1. 피사체

- 무엇 또는 누구인지, 몇 명인지, 무엇을 하고 있는지.
- 인물이면 대략적 연령대, 표정, 자세, 옷차림. 실존 인물을 지목하지 않는다 — "20대 여성"
  처럼 일반적으로 쓴다.

## 2. 환경

- 실내·실외, 장소 유형, 시간대, 날씨.
- 예: "카페 창가", "가을 숲", "노을 지는 도심 옥상".

## 3. 스타일과 무드

- 사진 장르(인물·풍경·제품·음식·스트리트 등) — 어휘는 `style-vocabulary.md`.
- 분위기(밝고 경쾌한 / 차분한 / 드라마틱 등).
- 색감 방향(따뜻한 톤 / 차가운 톤 / 파스텔 / 비비드).

## 4. 조명

- 방향(정면광·측광·역광)과 질감(부드러운·강한). 색온도 숫자는 쓰지 않는다 — "따뜻한 오후
  햇살", "창가로 들어오는 부드러운 자연광" 처럼 말로 쓴다.

## 5. 구도 (선택)

- 사용자가 원할 때만. 가로·세로, 클로즈업·전신, 여백 정도.

## 문장으로 조립하기

다섯 축을 나열이 아니라 자연스러운 한 문단으로 잇는다.

- 나쁜 예: "여성, 카페, 창가, 따뜻한 조명, 캐주얼"
- 좋은 예: "카페 창가 자리에서 커피를 마시는 20대 여성, 오후의 부드러운 자연광이 얼굴에
  은은하게 비치는 캐주얼한 분위기의 사진"

## 부족한 정보

축 하나가 비었으면 지어내지 말고 묻는다. 다만 매번 다섯 축을 전부 확인받을 필요는 없다 —
이미 충분히 구체적으로 설명했으면 그대로 진행한다.
