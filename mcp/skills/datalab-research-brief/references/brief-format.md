# 리포트 틀

리포트는 **읽은 것만 옮겨 적은 것**이다. 조사 과정을 보여주는 보고서가 아니라 사용자가
바로 쓸 수 있는 요약이다.

## 틀

```
# {주제} 조사

## 한 줄 요약
{핵심을 한두 문장으로}

## 확인한 것
1. {사실 하나} — [{페이지 제목}]({URL})
2. {사실 하나} — [{페이지 제목}]({URL}) · [{다른 페이지 제목}]({URL}) (두 곳에서 확인)

## 못 확인한 것
- {궁금하지만 읽은 페이지에 없었던 것, 또는 못 읽은 것}

## 수요 (있으면)
- 지식iN 질문 수: N건
```

## 넣지 않는 것

아래는 리포트에 넣지 않는다. 요청받아도 왜 안 되는지 설명한다.

| 넣지 않는 것                                           | 왜                                             |
| ------------------------------------------------------ | ---------------------------------------------- |
| 출처별 신뢰도 점수, 색깔 등급                          | 점수를 매길 도구가 없다. 지어낸 숫자가 된다    |
| 관련성 %, 검증률 %, 평균 신뢰도                        | 계산할 방법이 없다. 인용이 같은 일을 더 잘한다 |
| "품질 보증" · "전문가 검토 완료" 절                    | 아무도 검토하지 않았다                         |
| 결과수·기간·언어·지역을 구조화된 양식으로 받는 입력 폼 | 그런 옵션이 없는데 물어보게 된다               |
| 비교표의 신뢰도 표시                                   | 표시할 신뢰도 자체가 없다                      |

## 길이

리포트가 조사에 쓴 노력보다 길어지면 뭔가 잘못됐다. 확인한 사실 5~10개면 충분하다.
