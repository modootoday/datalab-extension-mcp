# 슬라이드 구조

## 역할

- **HOOK** — 첫 장. 시선을 끄는 한 줄 + 넓은 텍스트 공간.
- **INFO** — 정보 전달. 아이콘·번호 + 여백 중심.
- **VISUAL** — 이미지가 주인공, 텍스트는 최소로.
- **STORY** — 사례나 경험을 서술.
- **CTA** — 마지막 장. 행동 유도 문구 + 계정·링크.

슬라이드가 2장뿐이면 HOOK + CTA로 충분하다. 5~7장이면 HOOK 1 + INFO/VISUAL 3~5 + CTA 1이
흔한 배분이다. 슬라이드 수가 늘어난다고 억지로 다섯 역할을 다 채우지 않는다.

## 텍스트 요소 — 넣기 전에 정할 것

검증해 주는 도구는 없으니 상한을 넘겨도 오류는 나지 않는다. 카드 안에서 잘려 보이지 않게
스스로 지키는 기준으로 쓴다.

| 요소       | 용도                    | 대략 상한 | 비고                    |
| ---------- | ----------------------- | --------- | ----------------------- |
| 타이틀     | 슬라이드 메인 헤드라인  | 20자      | 모든 슬라이드에 필수    |
| 서브타이틀 | 타이틀을 보완하는 한 줄 | 40자      | 없어도 된다             |
| 본문       | 설명·불릿               | 100자     | INFO·STORY 슬라이드에만 |
| CTA        | 행동 유도 문구          | 15자      | CTA 슬라이드에만        |
| 캡션       | 출처·계정 핸들          | 30자      | 선택                    |

## 여러 페이지를 만들 때 지킬 것

- 배경 처리(단색·그라데이션·패턴)를 슬라이드마다 바꾸지 않는다. 한 번 정했으면
  `photo_template_apply` 로 나머지 페이지에 반복 적용한다.
- 로고·워터마크를 넣기로 했으면 모든 페이지에서 같은 위치를 쓴다.
- 아이콘·스티커 스타일(라인·필·입체)을 슬라이드마다 섞지 않는다.
- 색 팔레트는 3~4개로 제한한다. 슬라이드마다 새 색을 추가하면 일관성이 깨진다.

## 용도별 비율

| 용도        | 비율            |
| ----------- | --------------- |
| 인스타그램  | 1:1 또는 4:5    |
| 페이스북    | 1:1 또는 가로형 |
| 링크드인    | 1.91:1 또는 1:1 |
| 발표자료·PT | 16:9            |

발표자료는 역할 이름표만 다르다 — HOOK 대신 표지, INFO 대신 본문, CTA 대신 맺음. 구조는
같고 화면이 크니 글자수는 조금 넉넉해도 된다(타이틀 30자, 본문 150자).

비율을 모르면 인스타그램 1:1을 기본값으로 쓰고, 나중에 바꿔야 하면 다시
`photo_canvas_resize` 를 부른다.
