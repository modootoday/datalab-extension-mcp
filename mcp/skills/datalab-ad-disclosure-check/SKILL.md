# 광고 표시 문구 점검

협찬·광고성 글에 표시 문구가 있어야 하는지, 있다면 초안에 그 문구가 실제로 있는지를
확인한다. **판정 도구가 아니다.** 표시 문구가 있는지 없는지를 원문 인용과 함께 사실대로
보여주는 것까지가 이 스킬의 일이다.

## 무엇을 읽고 시작하나

사용자가 붙여넣은 글이 유일한 입력이다. 도구로 에디터를 대신 읽지 않는다 — 광고 표시
여부는 결과가 무거운 판단이라, 사용자가 무엇을 검토 대상으로 삼았는지 스스로 알고 있어야
한다.

글이 없으면 붙여넣어 달라고 하고 멈춘다. **지어내지 않는다.**

## 절차

**1. 경제적 이해관계가 있는지 먼저 확인한다.**
현금·제품·상품권·적립포인트·할인·고용 관계·판매 수수료 중 하나라도 광고주로부터 받았는지
사용자에게 확인한다. 없다고 답하면 표시 의무 논의 자체가 필요 없다 —
`references/ad-disclosure-rules.md` §1 의 예외 항목을 인용하고 종료한다.

**2. 있다면 어떤 매체인지 확인한다.**
글(블로그 본문) / 사진 / 동영상 / 실시간 방송 — 매체마다 표시 위치와 형식 요건이 다르다.
`references/ad-disclosure-rules.md` §3 에서 해당 매체 항목만 인용한다.

**3. 초안을 대조한다.**
붙여넣은 글에서 표시 문구를 찾는다. 찾았으면 그 문장을 그대로 인용하고 §3 의 요건과
비교해 위치·명확성 조건을 충족하는지 **사실만** 말한다 (예: "제목이 아니라 본문 중간에
있다", "'체험단'이라고만 쓰여 있는데 §2 는 이것을 명확한 표시로 보지 않는 예로 든다").
못 찾았으면 "표시 문구를 찾지 못했다"고만 말한다.

**4. 결과를 낸다.**

```
## 표시 의무
{예/아니오/불명확} — 근거: {ad-disclosure-rules.md 해당 절 인용}

## 초안 대조
- 발견한 표시 문구: {"..." 그대로 인용} 또는 "찾지 못함"
- 매체별 요건 대조: {§3 항목과 비교한 사실}

## 확인이 필요한 부분
{판단하지 않고 사용자가 직접 확인해야 하는 지점}
```

## 지어내지 않는다

- `references/` 두 파일에 없는 조항 번호·고시명·판례 번호는 **쓰지 않는다.** 모른다고
  말하고 멈춘다.
- "위반입니다" / "괜찮습니다" / "안전합니다" 라는 최종 판정을 **내리지 않는다.** 표시
  문구가 안 보인다는 것은 사실이지 위반 판정이 아니다 — 사진 안이나 첫 댓글처럼 이 스킬이
  못 보는 곳에 있을 수 있다.
- 위험도 점수·과징금 예상액·적발 확률 같은 수치를 만들지 않는다. 셀 방법이 없다.

## 없는 것 (찾지 마라)

- 이용약관·개인정보처리방침·면책조항을 **작성**하는 기능은 없다. 이미 쓴 글을 점검만 한다.
- 부동산·금융상품·환경 표시광고, 임시중지명령, 과징금 산정은 다루지 않는다.
  `references/ad-disclosure-rules.md` 밖의 질문이 오면 범위 밖이라고 말한다.
- 글을 대신 고치거나 에디터에 적용하는 기능은 없다. 무엇이 필요한지만 말한다.

## 면책

이 스킬의 결과는 법률 자문이 아니다. 실제 위반 여부와 제재 수준 판단은 변호사 또는
공정거래위원회 상담을 통해 확인해야 한다.

번들된 원문은 **특정 시점의 사본**이고 법령은 개정된다. 매 답변에서 인용이 사본
기준임을 밝히고, 실제 판단 전에 현행 조문을 확인하라고 안내한다.
