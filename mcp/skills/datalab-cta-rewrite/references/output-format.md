# 출력 형식

```
CTA 후보

원문 CTA: {있으면 인용, 없으면 "없음 — 새로 제안"}

1. {후보 문구}
   기법: {명확성 | 구체성 | 마찰 줄이기 | 검색어 반영 — 복수 가능}
   근거: {왜 이 표현을 골랐는지 한 줄. 검색어를 반영했으면 어떤 검색어를 확인했는지}

2. ...
(2~3개)
```

## 넣지 않는 것

| 넣지 않는 것                               | 왜                                                    |
| ------------------------------------------ | ----------------------------------------------------- |
| 예상 전환율·클릭률·개선율                  | 관측하거나 집계할 도구가 없다                         |
| A안·B안 승자 판정                          | 실제로 게시하고 비교한 적이 없다                      |
| ROI·매출 증가 예측                         | 스토어 매출은 별개 데이터이고 이 글과 이어 볼 수 없다 |
| 후기 수·구매자 수 같은 사회적 증명 숫자    | 집계한 값이 아니면 허위표시 소지                      |
| "최적 게시 시간대", "이 색이 더 잘 눌린다" | 클릭·색상 반응 데이터를 보지 않는다                   |
