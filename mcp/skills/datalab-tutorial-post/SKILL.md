# 튜토리얼형 블로그 글쓰기

개념 하나를 초보자가 따라올 수 있게 설명하는 블로그 글 **한 편**을 쓴다.

## 언제 쓰나

- "쉽게 설명하는 글 써줘", "입문자도 이해할 수 있게", "비유를 들어서 설명해줘"
- 개념 하나를 다루는 블로그 글 1편. 여러 챕터로 나뉜 코스나 강의 자료 요청이면 아래
  "여러 편으로 나눠야 할 때"를 먼저 본다.

## 글자수 — 12,000자가 상한이다

초안 한 번의 결과는 최대 약 12,000자다. 모델 응답 길이 상한이라 **재시도해도 늘어나지
않는다.** 이 스킬은 그 안에서 문제→해법→실습을 완결시킨다. 단계별 배분은
`references/structure-and-length.md`.

짧게 나왔다고 "더 길게" 다시 쓰지 않는다. 12,000자에 못 미치면 그 자체로 완결된
글이다 — 억지로 예시를 추가해 채우지 않는다. 길이가 모자라 보인다고 다시 쓰면 매번
과금되고 결과는 늘지 않는다.

## 절차

1. **주제와 독자를 확인한다.** 무엇을 설명할지, 읽는 사람이 이 개념을 왜 어려워하는지
   한 줄로 파악한다. 모르면 묻는다 — 지어내지 않는다.
2. **아이스브레이커로 연다.** 톤과 여는 방식은 `references/tone-and-hooks.md`.
3. **문제→해법→실습 구조로 쓴다.** 배분은 `references/structure-and-length.md`.
4. **비유나 사례를 하나 쓴다.** 템플릿은 `references/analogy-and-case-templates.md`.
   사례는 지어내지 않는다 — 확인 가능한 사실이거나 일반화된 상황("한 마케터가…")만 쓴다.
5. **막히는 대목이 있으면** `kin_question_demand` 로 사람들이 실제로 뭘 묻는지,
   `web_read` 로 사실을 확인한다. 짐작으로 채우지 않는다.
6. **발행.** 열린 에디터가 있으면 `outline_suggest` 로 구조를 잡고 `write_draft` 로 초안을
   쓴 뒤 `editor_insert_draft` 또는 `editor_place_draft` 로 넣는다. 열린 에디터가 없으면
   초안 텍스트를 그대로 돌려준다 — 그게 실패가 아니라 기본 경로다.

## 여러 편으로 나눠야 할 때

주제가 원래 크면(예: "입문부터 실무까지 전부") 한 편에 욱여넣지 않는다. "1편: 개념과
기본기, 2편: 실전 적용" 식으로 시리즈를 제안한다. 각 편은 이 절차를 그대로 다시 따르는
독립된 글이다.

## 하지 않는 것

요청받아도 아래는 만들지 않는다. 왜 안 되는지 설명하고 대안을 제시한다.

| 하지 않는 것                                   | 왜                                                                            |
| ---------------------------------------------- | ----------------------------------------------------------------------------- |
| 최소 글자수를 채우기 위한 재작성               | 12,000자 상한과 충돌하고, 다시 쓸 때마다 과금된다                             |
| 여러 챕터로 이어지는 코스 구성                 | 회차를 넘나드는 진행 상태를 이 표면이 추적하지 않는다. 시리즈로 나눠 제안한다 |
| 외부 문서도구 전용 서식(토글·콜아웃·DB 임포트) | 이 패널은 네이버 에디터에 쓴다                                                |
| 배지·경험치·진행률 바·수료증                   | 추적할 상태가 없고, 완료자 수 같은 없는 숫자를 지어내게 된다                  |
| 인물에게 귀속된 명언                           | 실제로 그 사람이 한 말인지 확인할 방법이 없다                                 |
| 자가평가 점수("15-20점: 마스터 레벨")          | 셀 수 없는 걸 숫자로 포장하는 패턴                                            |
| 다이어그램 문법                                | 네이버 에디터가 렌더링하는지 실측되지 않았다 — 텍스트 설명으로 대체한다       |
