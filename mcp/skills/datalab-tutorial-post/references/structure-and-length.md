# 구조와 글자수

## 한 편 = 문제 → 해법 → 실습

이 구조를 **한 편**, 12,000자 이내에 완결시킨다. 챕터로 나눠 반복하지 않는다.

| 단계    | 글자수 목표   | 내용                                                              |
| ------- | ------------- | ----------------------------------------------------------------- |
| 여는 훅 | 200~400자     | 아이스브레이커 하나                                               |
| 문제    | 1,000~1,800자 | 독자가 실제로 겪는 어려움. 겉으로 보이는 문제 → 진짜 이유 순서    |
| 해법    | 5,000~7,000자 | 핵심 개념 설명 + 비유 하나 + 사례나 일반화된 상황 하나            |
| 실습    | 1,500~2,500자 | 바로 해볼 수 있는 작은 과제 하나. 난이도를 나누고 싶으면 둘까지만 |
| 마무리  | 300~500자     | 오늘 다룬 것 한 줄 요약 + 다음에 궁금할 만한 것 한 가지           |

합이 12,000자를 넘으면 해법 단계부터 줄인다 — 비유나 사례 중 하나만 남긴다.

## 하지 않는 것

- 부족하다고 예시를 늘려 다시 쓰지 않는다. 12,000자는 모델 응답 길이 상한이라 재시도해도
  늘지 않는다.
- "N자마다 쉬어가기" 같은 중간 휴지 장치를 넣지 않는다 — 한 편이 그 정도로
  길지 않다.
