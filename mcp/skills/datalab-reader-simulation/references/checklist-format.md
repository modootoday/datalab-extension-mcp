# 점검 목록 형식

```
독자 프로필 (확인된 것만)
- 유입: {값}
- 유입 도메인 상위: {값}
- 기기: {값}
- 국가: {값}
- 재방문율: {값}
- 평균 체류: {값}
- 팔로워: {값}
- 성별/연령: {값 — 도구가 안 주면 이 줄 자체를 뺀다}

실제로 묻는 질문 (지식iN·검색, 확인된 것만)
1. {질문 또는 검색 표현} — {수치, 있으면}
2. ...

초안 대조
| 확인된 질문 | 초안에 답이 있나 | 근거 |
| --- | --- | --- |
| {질문} | 있음 / 없음 / 부분적 | {초안의 해당 부분, 없으면 "해당 문단 없음"} |

형식 메모 (프로필 측정값에 딸린 일반 원칙만)
- {예: 모바일 비중이 높은데 5줄 넘는 문단이 3곳}
```

이 목록은 실제 독자 반응이 아니다. 초안이 **확인된 질문**에 답했는지 대조한 것뿐이다.

## 채우지 않는 칸

- 도구가 값을 안 준 프로필 항목은 줄 자체를 쓰지 않는다 — "정보 없음" 같은 채움말도 쓰지
  않는다. 줄이 없어야 그 데이터가 없다는 게 분명하다.
- 확인된 질문이 하나도 없으면 "확인된 질문 없음"이라고만 쓰고 형식 메모만으로 마친다.
  질문을 지어내 채우지 않는다.
- 프로필과 질문이 둘 다 없으면 대조 자체를 하지 않는다 — 근거 없는 대조는 발행 준비가 된
  듯한 착각을 준다. 무엇이 없어서 못 하는지만 말하고 멈춘다.
