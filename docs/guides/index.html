한 줄 프롬프트로 일을 끝내요

한 번 붙여넣으면 AI가 필요한 도구를 차례로 불러 일을 끝까지 해요. 복사해서 내 키워드와 기간만 바꿔 쓰세요.

바로 조회묻지 않고 바로 써요매번 물어봄실행 전에 사이드패널에서 허용을 받아요

좋은 한 줄 프롬프트 쓰는 법

  • 끝낼 일을 말해요. "보여 줘"보다 "정리하고 3개 추천해 줘"처럼 마지막 결과를 적어요.
  • 대상과 기간을 넣어요. 키워드, 매장, "이번 주"나 "11월 1일부터 7일까지"처럼요.
  • 원하는 모양을 말해요. 표, 목록, 3개처럼 받고 싶은 형태를 적으면 바로 쓸 수 있어요.
  • 바꾸는 일은 한 번 더 확인해요. 글쓰기 창에 넣는 일은 사이드패널에서 허용해야 실행되고, 발행은 언제나 직접 해요.

자세히: 주간 성과 정리와 다음 주 글감

첫 번째 프롬프트를 붙여넣으면 AI는 아래 순서로 도구를 불러요. 결과가 마음에 들지 않으면 단계마다 이어서 물어봐도 돼요.

10분바로 조회 도구만 써요

AI가 거치는 순서

  1. 한 주 전체를 읽어요

    브리핑으로 방문과 조회를 읽고, 날짜별 흐름으로 지난주와 비교해요.

    쓰는 도구: my_daily_brief, my_traffic_series
  2. 키워드별로 나눠요

    어떤 검색어로 들어왔는지 읽고, 키워드마다 방문과 증감을 표로 만들어요.

    쓰는 도구: my_inflow
  3. 잘된 글을 짚어요

    조회가 많았던 글을 키워드 표 옆에 붙여, 무엇이 통했는지 보여 줘요.

    쓰는 도구: my_top_content
  4. 다음 주 글감 3개를 골라요

    잘된 키워드와 가까우면서 경쟁이 낮은 키워드를 골라 이유와 함께 추천해요.

    쓰는 도구: keyword_opportunity

이 프롬프트를 쓸 때

  • 오늘 수치는 진행 중이라 어제와 바로 비교하면 낮게 보여요. "이번 주"는 어제까지로 읽어요.
  • 글감이 마음에 들지 않으면 "캠핑 말고 요리 쪽으로 다시"처럼 이어서 말하면 돼요.
