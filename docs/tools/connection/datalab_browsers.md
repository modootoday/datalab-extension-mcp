# 연결 브라우저

`datalab_browsers` · 바로 조회 · 내 컴퓨터

이 컴퓨터에 지금 연결돼 있는 브라우저 프로필을 알려준다. 항목마다 id, 브라우저 이름(browser), 사용자가 붙인 프로필 이름(label), 그 프로필에 로그인된 네이버 블로그 id(blogId, 로그아웃이면 null)가 있다 — blogId 는 계정을 가리키는 값이다. 열려 있는 글도 로그인한 계정도 프로필마다 다르다. 목록의 id 를 다른 도구 호출의 browser 인자에 넣으면 그 브라우저에서 실행된다. 프로필이 둘 이상 연결돼 있으면 무언가를 바꾸는 도구는 browser 를 지정해야 실행되고, 조회 도구는 생략하면 primary 가 true 인 브라우저에서 실행된다. 어디서 할지 모르면 사용자에게 확인한다. 이 도구는 조회만 한다 — 브라우저는 사용자가 그 프로필에서 사이드패널을 열면 연결된다.
