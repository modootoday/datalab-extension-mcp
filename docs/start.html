처음 연결하기

확장에서 켜고, 연결 프로그램을 설치하고, 사이드패널에서 허용하면 끝나요. 처음이어도 보통 10분이면 돼요.

준비물

컴퓨터마다 한 번씩만 준비하면 돼요.

  • 데이터랩툴즈 확장크롬, 엣지, 웨일 같은 크로미움 브라우저에 app.datalab.tools에서 설치해요.
  • 컴퓨터에 설치하는 AI 앱Claude Desktop, ChatGPT 데스크톱, Claude Code, Codex 같은 앱이에요. 웹사이트로 쓰는 AI는 아직 연결되지 않아요.
  • Node.js 22 이상연결 프로그램을 실행하는 무료 프로그램이에요. 없다면 아래 설치 방법을 따라 해요.
{% include dl/callout.html type="warning" title="회사 컴퓨터라면" body="보안 정책 때문에 설치가 막혀 있을 수 있어요. 시작하기 전에 IT 담당자와 먼저 상의하면 시간을 아낄 수 있어요." %}

1단계: 확장에서 켜기

  1. 사이드패널 열기

    브라우저 오른쪽 위의 데이터랩툴즈 아이콘을 눌러요. 안 보이면 퍼즐 조각 아이콘에서 찾아요.

  2. 설정 열기

    패널 아래쪽 설정을 눌러요.

  3. 스위치 켜기

    다른 AI 앱에 연결 (MCP) 스위치를 켜고, 동의 화면의 문장을 읽고 동의해요.

{% include dl/callout.html type="note" id="consent" title="동의 화면 문장" body="연결된 AI 앱이 요청하면 네이버 데이터가 해당 앱과 그 AI 제공사 서버로 전달돼요." %}

2단계: 연결 프로그램 설치하기

방법은 둘이에요. 편한 쪽 하나만 하면 돼요.

{% include dl/home/install.html %}
  • 명령어로 설치하면컴퓨터에 있는 AI 앱을 모두 찾아 한 번에 등록해요. "연결할까요?"라고 물으면 엔터를 눌러요.
  • AI에게 맡기면Claude Code, Codex, Gemini CLI처럼 명령을 실행할 수 있는 앱이 설치와 등록을 해 줘요.
  • 터미널 여는 법Windows는 검색창에 cmd, Mac은 ⌘+스페이스로 터미널을 찾아 열어요.

AI 앱 설정에는 데이터랩툴즈 항목만 더하고, 다른 항목은 건드리지 않아요.

Node.js가 없다면

설치 명령이 npx를 찾을 수 없다고 하면 Node.js가 없는 거예요. nodejs.org의 LTS 버튼으로 받거나, 아래 명령으로 설치한 뒤 설치 명령을 다시 실행해요.

Windows

winget install OpenJS.NodeJS.LTS

Mac · Linux

curl -fsSL https://app.datalab.tools/install/mcp.sh | sh

Mac · Linux 명령은 Node.js를 관리자 권한 없이 설치하고 연결까지 이어서 해요. 실행하기 전에 주소를 브라우저로 열면 스크립트 원문을 볼 수 있어요.

AI 앱의 플러그인으로 설치하기

Claude Code

claude plugin marketplace add modootoday/datalab-extension-mcp
claude plugin install datalab-extension-mcp@modootoday

Copilot CLI

copilot plugin install modootoday/datalab-extension-mcp

Gemini CLI

gemini extensions install https://github.com/modootoday/datalab-extension-mcp

Antigravity

agy plugin install https://github.com/modootoday/datalab-extension-mcp

VS Code는 명령 팔레트의 "Chat: Install Plugin from Source"에 저장소 주소를 넣어요.

연결되는 AI 앱

  • 자동으로 등록돼요Claude Desktop, Claude Code, ChatGPT 데스크톱, Codex CLI, Gemini CLI, Cursor, Windsurf, Amazon Q Developer, JetBrains Junie, Kiro
  • 화면 안내를 따라 등록해요VS Code, Zed, Cline, Roo Code, LM Studio, Warp

3단계: 사이드패널에서 허용하기

  1. AI 앱을 완전히 종료했다 켜기

    창만 닫으면 뒤에서 계속 실행돼요. Windows는 트레이 아이콘에서 종료, Mac은 ⌘+Q, Linux는 앱 메뉴의 Quit으로 종료해요.

  2. 허용하기 누르기

    사이드패널을 열어 둔 채 AI 앱에서 데이터랩툴즈를 처음 쓰면 패널이 허용할지 물어요. 10분 안에 [허용하기]를 눌러요. 직접 시작한 연결이 아니라면 [거절하기]를 눌러요.

  3. 초록색 카드 확인하기

    카드가 초록색이고 "연결됨"이 보이면 된 거예요. AI 앱에 "지난주 내 블로그 어땠어?"처럼 물어보세요.

{%- capture _green %}초록색이 아니면 문제 해결에서 카드에 보이는 문장을 찾아요.{% endcapture %} {% include dl/callout.html type="tip" title="카드가 초록색이 아니라면" body=_green %}

브라우저 프로필 하나 더 연결하기

처음 [허용하기]를 누른 브라우저 프로필이 이 컴퓨터의 연결 프로그램과 연결돼요. 같은 컴퓨터의 다른 프로필도 쓰려면 이렇게 해요.

  1. 연결 키 복사하기

    연결된 프로필의 확장 설정에서 다른 AI 앱에 연결 (MCP)의 연결 키를 복사해요.

  2. 새 프로필에 붙여넣기

    새 프로필의 같은 화면에 붙여넣어요.

{% include dl/callout.html type="note" title="한 컴퓨터 안에서만 돼요" body="연결 프로그램은 이 컴퓨터 안에서만 연결을 받고, 연결 키는 다른 사람에게 보내는 것이 아니에요. AI 앱이 지금 어느 프로필에 닿는지는 datalab_browsers로 물어보면 돼요." %}

스킬 카탈로그

설치할 때 스킬 카탈로그(skills.modoo.today)도 함께 연결돼요. 스킬 파일을 컴퓨터에 복사하지 않고, AI 앱이 필요할 때 받아 써요.

  • 연결Claude Code와 Codex는 자동으로 연결돼요. 다른 앱은 설치가 끝날 때 보여 주는 안내대로 원격 서버 https://skills.modoo.today/mcp를 추가해요.
  • 로그인처음 쓸 때 modoo.today 로그인 창이 한 번 열려요.
  • 빼고 설치하기설치 명령 끝에 --no-skills를 붙이면 확장만 연결해요.

알아 두면 좋은 것

  • 사이드패널이 열려 있는 동안 연결돼요패널을 닫으면 연결도 끊기고, 다시 열면 자동으로 이어져요.
  • 새 버전은 알아서 받아요안전한 최신 버전을 확인해 두고, 다음에 AI 앱을 켤 때부터 써요.
  • 아이디와 비밀번호를 저장하지 않아요조회는 내가 로그인해 둔 내 브라우저 안에서 일어나요. 자세한 내용은 개인정보와 안전에 있어요.

연결 해지하기

  1. AI 앱 설정에서 지우기

    터미널에서 아래 명령을 실행하면 AI 앱에 등록한 데이터랩툴즈 설정을 지워요.

    npx -y {{ install.package }}@{{ install.version }} uninstall
  2. 확장에서 끄기

    확장 설정에서 다른 AI 앱에 연결 (MCP)을 꺼요. 설정이 어딘가 남아 있어도 AI 앱이 아무것도 조회할 수 없어요.
