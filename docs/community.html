GitHub Discussions

쓰는 사람끼리 묻고 답해요

질문, 사용 사례, 새 도구 제안을 GitHub Discussions에 모아요. 답이 채택된 질문은 다음 사람이 검색으로 바로 찾을 수 있어요.

커뮤니티로 가기질문하기

어디에 쓰면 될까요

공지

새 버전, 바뀐 설치 방법, 도구 변경을 알려요. 운영자만 글을 써요.

질문과 답

설치, 연결, 도구 사용법을 물어요. 도움이 된 답을 채택해 주세요.

사용 사례

이렇게 물었더니 이렇게 쓰였다는 경험을 나눠요. 수치는 가리고 흐름만 보여 주세요.

도구 제안

있었으면 하는 도구나 묶음을 제안해요. 공감 표시가 많은 제안부터 검토해요.

오류는 Issues로

도구가 틀린 값을 주거나 멈췄다면 Issues에 남겨요. 버전과 쓰는 AI 앱을 적는 칸이 있어요.

함께 지키는 약속

모두가 편하게 묻고 답하도록 지켜 주세요.

  • 질문 전에 검색해 보고, 해결되면 도움이 된 답을 채택해요.
  • 어느 AI 앱과 버전에서 생긴 일인지 적어요.
  • 블로그 주소, 네이버 아이디, 광고 계정 번호, 실제 수치가 보이는 화면을 올리지 않아요.
  • 설치 인증키나 설정 파일 전체를 붙여넣지 않아요.
  • 홍보, 다른 사람을 깎아내리는 말은 지워져요.
